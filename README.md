# EVE Trader

A CLI tool for analyzing EVE Online Jita market opportunities.

## Features

- Fetch Jita market orders from EVE ESI API
- Calculate buy/sell spread
- Calculate broker fees and sales tax
- Calculate real ROI after fees

## Usage

```bash
go run ./cmd/trader
```

## Example

```text
Buy: 826300 ISK
Sell: 885900 ISK
ROI: -4.04%
```
